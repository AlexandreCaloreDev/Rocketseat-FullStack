# SQLite

## Conceito
- Banco de dados **relacional**.
- Utiliza estrutura de **tabelas (linhas e colunas)**.

## Características

### Leve
- Baixo consumo de recursos.
- Ideal para ambientes simples e aprendizado.

### Arquivo Único
- Todo o banco fica em **um único arquivo**:
  - Dados
  - Estrutura (tabelas)
  - Índices
- Facilita transporte e gerenciamento.

### Autossuficiente
- Não requer:
  - Servidor separado
  - Instalação complexa
- Funciona **embutido na aplicação**.

## Funcionamento
- Pode ser acessado via:
  - Código da aplicação
  - SGBD (Sistema Gerenciador de Banco de Dados)
- Manipulação feita via **SQL**.

## Uso

### Estudos
- Ambiente simples e direto.
- Foco em:
  - Banco de dados relacional
  - SQL

### Produção
- Utilizado em:
  - Aplicações mobile
  - Aplicações web
- Adequado para projetos menores ou embarcados.

## Vantagens
- Simplicidade
- Portabilidade
- Zero configuração
- Rápida implementação

## Síntese
- Banco relacional compacto.
- Armazena tudo em um único arquivo.
- Ideal para aprendizado e aplicações leves.
