# Introdução a Banco de Dados — Resumo de Estudo

## Dado vs Informação

### Dado
- É um valor bruto, isolado.
- Não possui significado sozinho.
- Exemplo: `2006`
  - Pode ser ano, código ou qualquer outra coisa.

### Informação
- É o resultado da organização e interpretação dos dados.
- Possui significado e contexto.

### Relação entre eles
- Dados organizados → geram informação.
- Informação depende de dados estruturados.

### Exemplo
- Dados:
  - Nome: João
  - Ano: 2006

- Informação:
  - João nasceu em 2006.
  - João tem 18 anos.

---

## O que é um banco de dados
Banco de dados é uma **coleção organizada de dados**.

Seu objetivo é:
- Armazenar dados.
- Organizar dados.
- Permitir acesso e manipulação eficiente.

---

## Por que usar banco de dados

### 1. Organização
- Dados estruturados de forma lógica.
- Facilita entendimento e manutenção.

---

### 2. Acesso e manipulação
- Permite buscar, alterar e processar dados facilmente.
- Facilita extração de informações.

---

### 3. Escalabilidade
- Suporta grande volume de dados.
- Cresce junto com a aplicação.

---

### 4. Eficiência e performance
- Otimizado para leitura e escrita de dados.
- Responde rapidamente a consultas.
- Reduz tempo de acesso à informação.

---

### 5. Integridade e consistência
- Regras garantem que os dados sejam válidos.
- Exemplo:
  - Campo numérico aceita apenas números.
  - Campo de texto aceita apenas texto.

Evita dados incorretos ou inconsistentes.

---

### 6. Segurança e confiabilidade
- Dados protegidos dentro do sistema.
- Redução de erros e perda de informação.

---

## Estrutura de dados
- Dados são organizados em estruturas (ex: tabelas).
- Cada campo possui um tipo definido.
- O banco garante que os dados respeitem essa estrutura.

---

## Conclusão
Banco de dados transforma dados brutos em informação útil através de organização, estrutura e regras.

Ele é essencial para:
- Armazenamento persistente.
- Acesso eficiente.
- Garantia de integridade dos dados.
