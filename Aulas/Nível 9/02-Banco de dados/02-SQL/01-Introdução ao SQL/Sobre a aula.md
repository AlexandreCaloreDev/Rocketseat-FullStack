# SQL (Structured Query Language)

## Conceito
- Linguagem padrão para **bancos de dados relacionais**.
- Utilizada para **gerenciar e manipular dados**.

## Função
Permite executar operações como:
- Criar estruturas (tabelas, bancos)
- Inserir dados
- Consultar dados
- Atualizar dados
- Deletar dados

## Portabilidade
- Funciona em diferentes bancos relacionais:
  - SQLite
  - PostgreSQL
  - SQL Server
- Diferenças existem, mas são **pontuais**:
  - Sintaxe específica
  - Regras (ex: ponto e vírgula obrigatório ou não)
  - Uso de aspas

## Padronização
- Base comum entre bancos:
  - Mesmos comandos principais
  - Mesma lógica de manipulação de dados
- Conhecimento reaproveitável entre tecnologias.

## Exemplos de Uso
- Consultar registros → leitura de dados
- Inserir registros → criação de dados
- Atualizar registros → modificação
- Remover registros → exclusão

## Síntese
- Linguagem central para interação com bancos relacionais.
- Independente de tecnologia específica.
- Base para qualquer operação de dados estruturados.
